   # sre-lab

   My hands-on path from QA Lead to Site Reliability Engineer.

   Building one production-style system step by step:
   Linux → Azure → Docker → CI/CD → Kubernetes → Terraform → Observability & SLOs → Chaos & postmortems → AI infrastructure.

   ## Structure
   - `phase1/` – Linux server, Nginx, systemd
   - `phase2/` – Containers, Azure, CI/CD
   - `phase3/` – Kubernetes (AKS) and Terraform
   - `phase4/` – Monitoring, SLOs, chaos engineering, postmortems
   - `journal.md` – weekly notes on what I learned and what broke
